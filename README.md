# カタン オンライン版 v1.37

GitHub Pages＋Cloudflare Workers＋Durable Objectsで動く私用オンライン版です。

## 内容

- 固定4部屋
- 3～6人
- ホストが人数と漁師拡張ON/OFFを設定
- 設定人数と接続人数が一致すると開始可能
- 全員がブラウザから参加
- ゲーム状態を部屋ごとにDurable Objectへ保存
- 切断後、同じブラウザなら同じ席へ再接続
- ホストの「ロビーへ戻す」で対戦を終了して同じ参加者でロビーへ戻る
- 鉱石アイコンを🪨へ変更
- 湖タイル画像は `assets/tiles/lake.webp` または `lake.png`

## GitHub Pagesへ置く物

この `github-pages` フォルダの中身を、GitHubリポジトリのルートへアップロードします。

- index.html
- style.css
- game.js
- online.js
- config.js
- assets
- .nojekyll

## Worker URL

標準設定は次のURLです。

`https://catan-online-server.naitoryo7110.workers.dev`

Cloudflareで別のURLが表示された場合、`config.js` のURLだけ書き換えてください。

## 現在の同期方式

私用ゲームとして扱いやすいよう、各手番のブラウザが状態を更新し、Durable Objectが部屋全員へ同期する方式です。
ゲーム状態は参加者のブラウザへ配信されるため、開発者ツールを使った秘匿情報の解析まで防ぐ設計ではありません。


## 追加のオンライン処理

- 7で複数人が捨てる場合、対象プレイヤーの画面へ順番に選択画面を表示
- 魚チップ7枚時の引き直しも、対象プレイヤー本人の画面で選択
- 対戦中にページを再読み込みしても、同じブラウザなら直前の部屋へ再接続
- 人間同士の交易は、相手画面へYES／NOを表示


## v1.37：確認用CPU

ロビーの「不足席をCPUで埋める（確認用）」をONにすると、設定人数に足りない席へCPUを追加できます。

例：

- 3人戦、人間1人 → CPU2人
- 4人戦、人間2人 → CPU2人
- 6人戦、人間1人 → CPU5人

CPUの手番処理は、その部屋のホストのブラウザが担当します。
通常のオンライン対戦では、この設定をOFFにしてください。

## v1.37 CPU一人プレイ修正

「CPU参加」は確認専用ではなく、通常の一人プレイ機能として使用できます。

- 人間1人＋CPU2～5人で3～6人戦を開始可能
- 自分の席は常に人間操作
- 初期配置は1周目と逆順2周目の両方を自分で操作
- CPU用タイマーが重複しても、人間の手番では実行されない
- 人間の手番へ移った瞬間に、残っているCPUタイマーを破棄
- CPUが7を出した後も、資源破棄と猫移動の後にCPUの建設処理へ復帰


## v1.37 タイル画像のちらつき修正

通信そのものではなく、状態更新のたびに盤面SVGを空にして、
タイル画像を作り直していたことが原因でした。

v1.37では次の処理へ変更しました。

- 更新前の完成済み盤面を一時的に上へ保持
- 新しいタイル画像を裏側で読み込み
- 全画像の読み込み完了後に古い盤面を外す
- 通信更新が連続しても、完成済み盤面を消さない
- ゲーム開始前にタイル画像をプリロード

これにより、行動ごとに地形が単色へ戻る表示を防ぎます。


## v1.37 部屋初期化・手番順

### 自動初期化

対戦中の部屋が0人になると、5分後に自動初期化します。

- 5分以内に元の参加者が再接続：対戦を継続
- 5分間0人のまま：ゲーム、参加者、ホストを削除してロビーへ戻す
- タイトル画面には自動初期化までのおおよその残り時間を表示

### タイトル画面から手動初期化

各部屋カードへ「初期化」ボタンを追加しました。
対戦中でも部屋を強制的に空へ戻せます。

### プレイヤー順

ゲーム開始時、人間とCPUをまとめてランダムに並べます。
初期配置の1番手から、このランダム順を使います。
ゲームログに決定した手番順を表示します。


## v1.37 交易と資源マイナス修正

- 相手の資源種類ごとの所持数を非公開
- 公開するのは資源カードの合計枚数だけ
- 相手が持っていない資源でも要求可能
- 回答者が要求資源を持つ場合だけYESを選択可能
- CPUは資源不足なら必ずNO
- 交易成立直前に双方の資源数を再確認
- 交易IDによる二重実行防止
- ブラウザ内にも処理済み交易IDを保持
- 既存の負数資源を0へ修復
- 銀行在庫を総枚数から再計算

以前は交易成立時に資源を直接減算しており、通信で古い提案が戻った場合に
同じ交易が二重処理される可能性がありました。0枚から再度1枚引かれると
-1になります。v1.37ではこの経路を塞いでいます。

スマホ版よりボタン・資源・駒表示を少し大きくし、
タブレットの横幅を使います。

### 自動切替

端末を回転すると、再読み込みせずに表示方法を切り替えます。

- 縦から横：PC型表示
- 横から縦：タブ型表示


## v1.37 縦持ちタブレットの盤面修正

縦持ちタブレットではスマホ式の
「盤面・操作・情報」タブを維持します。

ただし、スマホ版で使用している
X1～X19・Y3～Y17の盤面切り取りは適用しません。

変更点：

- 盤面上側の切り取りを解除
- 盤面全体を表示
- ダイス枠用の領域を盤面上部に確保
- ダイス枠の下へ盤面を配置
- 盤面の縦横比を維持
- 資源変動POUはダイス枠の下から表示

スマホ版の盤面切り取り設定は変更していません。


## v1.37 POP表示時間

ゲーム内のPOP表示時間を2秒へ統一しました。

対象：

- 資源獲得・支払い・交易などの資源変動POP
- 盗賊登場
- 発展カード取得・使用
- 漁師の効果
- 最長交易路
- 最大騎士団
- ボロ靴

JavaScriptの削除タイマーとCSSアニメーションを
どちらも2秒へ合わせています。


## v1.37 資源変動POPのオンライン同期

これまでは資源変動POPを操作したブラウザへ直接表示していたため、
ダイスを振ったプレイヤーにしか表示されませんでした。

資源変動を `resourcePopEvents` としてゲーム状態へ保存し、
部屋内の全プレイヤーへ同期する方式へ変更しました。

同期対象：

- ダイスによる資源獲得
- 初期資源
- 建設・発展カード購入の支払い
- 銀行・港交易
- プレイヤー交易
- 発見
- 独占
- 漁師の資源獲得
- 7の資源破棄
- 盗賊・漁師による資源強奪

### 非公開情報

7で捨てた資源の内訳：

- 捨てた本人：資源の種類を表示
- ほかのプレイヤー：不明カードとして枚数だけ表示

盗賊・漁師による強奪：

- 奪った人と奪われた人：資源の種類を表示
- 第三者：不明カードとして1枚だけ表示

POP表示時間は2秒のままです。


## v1.37 盗賊移動時の数字クリック

盗賊を移動する場面で、
タイル中央の数字チップもクリック対象にしました。

クリックできる場所：

- タイル本体
- 数字チップの丸い枠
- 数字
- 数字の下にある確率の点
- 湖タイルの数字
- 湖タイル中央の魚アイコン

どの部分を押しても、そのタイルへ盗賊を移動します。

盗賊が既にいる同じタイルを押した場合は移動しません。


## v1.37 ターン開始演出

通常ターンが次のプレイヤーへ移った時、
盤面中央へ次の形式で2秒間表示します。

`プレイヤーAのターン`

仕様：

- 初期配置のプレイヤー交代では表示しない
- 初期配置完了後の最初の通常ターンでは表示
- 以降、ターン終了ごとに表示
- プレイヤーカラーを左右の枠へ反映
- PC・スマホ・タブレット対応
- 部屋内の全プレイヤーへ同期
- 再接続時に過去のターン表示をまとめて再生しない


## v1.37 配置前の確認

人間プレイヤーが盤面上の場所を選んだ時、
すぐには配置せず確認画面を表示します。

表示：

`ここに置いていいですか？`

選択肢：

- はい：選択した場所へ配置
- いいえ：配置せず場所を選び直す

対象：

- 初期開拓地
- 初期街道
- 通常の開拓地
- 都市
- 通常の街道
- 街道建設カードの無料街道
- 漁師の無料街道
- 盗賊の移動

確認中は、選択した場所を白く点滅させ、
プレイヤーカラーで仮置き表示します。

確認画面は操作する本人だけに表示され、
「はい」を選ぶまで他プレイヤーには配置が同期されません。
CPUの配置には確認画面を出しません。


## v1.37 資源を奪う相手の確認

人間プレイヤーが資源を奪う相手を選んだあと、
すぐには強奪せず次の確認を表示します。

`この人から奪っていいですか？`

選択肢：

- はい：選択した相手から資源をランダムに1枚奪う
- いいえ：相手選択画面へ戻る

対象：

- 盗賊による資源強奪
- 漁師の「資源を奪う」

確認画面には相手のプレイヤー名を表示します。
CPUの強奪には確認画面を表示しません。


## v1.37 建設ボタンの表示

自分のターン以外でも、建設パネルの内容を
通常の明るさで確認できるようにしました。

対象：

- 街道
- 開拓地
- 都市
- 発展カード

変更したのは見た目だけです。

- 自分のターン以外は押せない
- ダイスを振る前は押せない
- 建設済みの場合は押せない
- ゲーム終了後は押せない

無効状態でも文字・必要資源・ボタン背景を薄くしません。
